## Evenements voisins : Antares, MSB, Le Mans FC (`voisins_sync.py`, 07/10/2026)

Ce qui se passe a cote du circuit et pese sur la circulation et le stationnement, ecrit dans la timeline SAISON et dans le calendrier d'occupation, sur le modele de Momentus.

- **Sources publiques, sans identifiant** (aucune n'est contractuelle) :
  - **Antares** : API REST WordPress `https://www.antaresarena.com/wp-json/wp/v2/event` (`per_page=100`, `X-WP-TotalPages`). Une seance = `acf.sessions[].session_date` (heure de Paris, plusieurs seances par spectacle : Holiday On Ice 5). `status_event` : `on_sale`, `soon` (billetterie pas ouverte), `cancelled`. Type = `class_list` `type-concert|spectacle|humour|sport...`. Titres avec entites HTML. ⚠️ Les matchs du MSB n'y sont PAS.
  - **MSB** (basket, joue a Antares) : API du site lnb.fr. Jeton anonyme 15 min par `GET https://lnb.fr/api/token` (sans lui : 403), puis `api-prod.lnb.fr` avec `Authorization: Bearer`, `Origin/Referer: https://lnb.fr`. `competition/getMainCompetition` -> `competition/getCompetitionTeams?competition_external_id=` (l'id d'equipe CHANGE chaque saison : 1864 en 2026, relu a chaque passage) -> `POST match/v3/getCalendar {year, team_external_id, competition_abbrev:"", division_external_id:0, round_number:0, phase_id:0, tournament_number:0}`. Domicile = `teams[0]`. `match_time_utc` ISO UTC. Calendrier publie par blocs (J1-J23 au 07/10/2026). ⚠️ Coupes d'Europe (FIBA) absentes.
  - **Le Mans FC** (stade Marie-Marvingt / MMArena) : API publique ESPN `site.api.espn.com/apis/site/v2/sports/soccer/{fra.1|fra.2|fra.coupe_de_france}/teams/2697/schedule` (+ `?fixture=true` pour le futur). Domicile = competitor `homeAway: home`. ⚠️ `timeValid: false` = date posee, horaire pas encore fixe par la LFP (diffuseurs, ~4-6 semaines avant) : `time` vide, `time_tbc: true`, "horaire a confirmer". TheSportsDB (cle gratuite) ne rend qu'un match a venir : inutilisable.
- **Collection `voisins_events`** : un doc par seance / match, `_id` `antares|<wp id>|<date>T<HHMM>`, `msb|<external_id>`, `fcmans|<espn id>` ; `venue` `antares` (spectacles + MSB) ou `stade` ; `status` `prevu` / `annule` ; `_sync {first_seen, last_seen, deleted_at}`. Rien n'est supprime. Reconciliation PAR SOURCE et seulement des evenements A VENIR (ESPN `fixture` ne rend plus les matchs joues) ; source en echec = intouchee ; source qui rend < 50 % de l'existant a venir = pas de reconciliation. Un spectacle Antares deplace change d'`_id` (l'ancien passe en supprime).
- **Flux estimes** (`voisins_sync.FLUX` / `FLUX_KIND`, minutes avant / apres l'heure) : foot 120 / 115, MSB 75 / 135, Antares 90 / 150 (humour, one-man-show 60 / 120 ; spectacle 75 / 150). ORDRES DE GRANDEUR, toujours libelles "estime" / "~". Aucun flux sans horaire (`time_tbc`).
- **Timeline SAISON** : par evenement, une vignette `voisins_role: "evenement"` (heure -> fin estimee, `activity` "Antarès : <spectacle>" ou "<titre> (<lieu>)") et, si l'horaire est connu, deux vignettes de flux `arrivees` (debut des arrivees -> heure) et `sortie` (fin estimee, 45 min), `department: "Flux public"`. `origin: "voisins"`, `category: "Voisins"`, `place` = lieu, remarque "Evenement voisin | lieu | type | ... | source". Champs `voisins_id`, `voisins_venue`, `voisins_source`, `voisins_icon`, `voisins_role`, `voisins_time_tbc`. Carte distincte (`createEventItem` : `.is-voisin` + `.vz-antares|.vz-stade`, bordure epaisse, pictogramme du type, badge Antarès / MMArena, chips "flux estimé" / "horaire à confirmer" ; flux en pointilles `.vz-flux`). Annules exclus. Ecriture par `momentus_timeline._sync_year_doc(..., origin="voisins")` : memes regles que Momentus (atomique par date, champs operateur conserves, vignette editee en entier = `manual-edit` hors synchro, purge avant J-7). Fenetre ecrite : la veille -> dernier evenement connu (400 j max) ; affichage borne J-1 -> J+14 comme le reste de SAISON.
- **Calendrier / barre des jours** : source d'indicateur `{type: "voisins", venue: "antares"|"stade"}` (`saison_indicateurs._voisins_details`). Defauts `voisin_antares` (ANT, #1F78B4, `stadium`) et `voisin_stade` (MMA, #4B5563, `sports_soccer`), rang point. Ajoutes UNE FOIS aux configurations existantes (`cockpit_settings.voisins_seeded`, pose aussi par tout enregistrement admin : un retrait est definitif). Details : `icon`, `venue_label`, `arrivals`, `end_est`, `subtitle`. Filtre de la timeline : `item.voisins_venue === ind.venue`. Admin : source "Evenements voisins" + lieu. Rendu (`timeline.js`) : barre des jours = pictogramme rond en coin du jour (`.si-vz-flag`, clic = filtre) ; infobulle (barre et calendrier) = encadre "À côté du circuit" EN TETE (`_siVoisinsBlock` : heure, titre, lieu · type · arrivees ~ / fin ~), les voisins ne sont pas repetes dans la liste des indicateurs ; calendrier = pastille pictogramme + heure dans la ligne du haut de la case (`.si-cal-vzpill`, +N si plusieurs) et liseré superieur (`.si-cal-has-vz`), PAS de bande en bas (coupee par la hauteur fixe des cases).
- **Bandeau "À côté du circuit"** (fin de `timeline.js`, `#vz-banner` en tete de `#timeline-main`) : evenements voisins d'aujourd'hui et demain, QUELLE QUE SOIT l'epreuve affichee (un concert pendant les 24H compte aussi). `GET /api/voisins?from=&to=` (user, `saison_indicateurs_api.py`, defaut aujourd'hui -> demain, 14 j max, `voisins_sync.public_event` : ni URL non https ni texte brut). Rafraichi toutes les 10 min et au retour sur l'onglet ; masque s'il n'y a rien. Clic = vignette de la timeline (si affichee, `data-vz-id`), sinon toast.
- **Tache** `scripts/install_voisins_task.ps1` (2 fois par jour, 06:15 et 13:15, `scripts/voisins_sync.bat`), statut dans `cron_status.json` ("Sync Voisins"). A la main : `python voisins_sync.py --dry-run`.
- Tests : `tests/test_voisins_sync.py` (extraits reels des 3 sources).
