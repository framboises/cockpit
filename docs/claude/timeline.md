## Timeline v2 (22/10/2026)

Refonte de l'affichage de la timeline de l'accueil (`timeline.js`, styles dans `static/css/timeline_v2.css`, charge apres `style.css`). Les donnees, routes et le tiroir de detail sont inchanges.

- **Vignettes** (`createEventItem` / `createClusterItem`) : classe `.event-item`, `data-minute`, `__itemData` / `__clusterData`, `.prep-chip`, `.cluster-line[data-child-id]` CONSERVES (recherche, ligne "maintenant", statuts en direct, filtre SAISON, bandeau d'en-tete de `main.js` en dependent). Balisage `.ev2` : titre + ligne secondaire (lieu, categorie hors palette, fin) + une colonne d'etat (`.ev2-cd` compte a rebours, ACO, acces, preparation, taches `.ev2-todo`, planning). Le clic ouvre le tiroir ; seules les taches se deplient sur place. Titres et lieux echappes (`_acoEsc`). Taches : voir `docs/claude/taches.md` (`item.tasks`, `tasksOf`).
- **Couleur de categorie** : bord gauche via classes `tlc-<slug>` / `tlc-fb-N` (`tlCatClasses`). Reglable dans Configuration > "Couleurs des categories (timeline)" (`timeline_cat_styles.js`, `cockpit_settings._id="timeline_categories"` `{items: [{slug, label, color, icon}]}`, routes `/api/timeline-category-styles` lecture user / PUT admin, `/catalog` admin). La timeline injecte `<style id="tl-cat-styles">` avec la classe doublee `.tlc-x.tlc-x` (l'emporte sur timeline_v2.css et le mode TV) ; un slug regle compte comme connu (`_tlCatConfigured`) ; l'icone reglee passe avant celle du type (`_tlIconFor`). Slug serveur `_tl_cat_slug` = meme normalisation que `_categorySlug`. Jamais `cat-*` sur la vignette (ces classes colorent le FOND des puces). Pas de `--cat` par defaut sur `.event-item` : la specificite ecraserait les `tlc-*` (repli gris par `var(--cat, #94a3b8)`).
- **Preparation** : sans statut ni taches (creneau piste, voisin), pas de pastille (sinon "En retard" des le debut). `prep-none` / `prep-done` masques sur la vignette.
- **Blocs horaires** `.tl-tb[data-minute]` (heure une seule fois) dans chaque `.timetable-date-section` ; en-tete du jour `.tl-dh` colle en haut. Les scrolls vers une vignette retranchent sa hauteur (`_siScrollTo`).
- **Passe replie** (`_tlApplyPast`, etat `TlState`) : jours passes replies s'il existe un jour courant ou a venir ; le jour meme, blocs passes derriere `.tl-pastbar` sauf ce qui est en cours et sauf s'il ne reste rien a venir. Tout code qui fait defiler vers une vignette appelle `_tlReveal(el)` (recherche, filtre d'indicateur, voisins). `_tlTick` toutes les 30 s : comptes a rebours + repli.
- **Barre des jours des epreuves** : memes pastilles / points / infobulle / legende / filtre que SAISON. `_siDecorate` = fetch API puis `_siPaint` ; `_epDecorate` calcule `{indicators, days}` depuis `window._timetableRaw` (`_epBuild`) et appelle `_siPaint` avec `SaisonInd.local = true` (sinon `_siApplyFilter` ignore hors SAISON). Indicateurs `source_type: 'epreuve'` portant leur `match(item)` : PUB (publicDatesMap), CRS (parametrage.race), PIS (origin `timetable`), NUIT (creneau >= 21:00 ou < 05:00), un point par type de `CLUSTER_CONFIG` (ouvertures), RET (preparation en retard, jour courant). Seuls les indicateurs actifs au moins un jour gardent une place.
- **Recherche** : `#timeline-searchbar` masquee en vue timeline sauf `body.tl-search-open` (loupe `#tl-search-btn`) ; la vue carte la garde (`body.tl-view-map`, synchronise au clic des boutons de vue).
- **Suivi de l'heure** (`NowLineController`, bouton d'en-tete) : un defilement manuel l'arrete et affiche `#tl-backnow` ; choix memorise (`localStorage tl_follow_now`).
- **Mode TV** (`tlTvOpen` / `tlTvClose`) : menu "Ecrans TV > Timeline" (`_sidebar.html`, `/?tv=1`, nouvel onglet). Calque plein ecran sombre, horloge, "En cours" (en cours ou depuis 20 min) et "A venir sur 3 h", rafraichi toutes les 10 s, wake lock. Pilote UNIQUEMENT par l'adresse (jamais en localStorage : l'onglet Cockpit de l'operateur basculerait en TV a son rechargement) ; l'ecran mural rouvert sur `/?tv=1` reste en TV. Echap ou croix : retour a la timeline, `?tv=1` retire de l'adresse. Cockpit PC n'a pas de theme sombre : seul le mode TV est sombre.
- **Gabarit absent ou ancien** : `_tlEnsureUi` cree la feuille `timeline_v2.css`, la barre d'outils et `#tl-backnow` s'ils manquent (gabarit en cache navigateur). Les gabarits Flask se rechargent a chaud (`TEMPLATES_AUTO_RELOAD`).
